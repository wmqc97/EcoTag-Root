# 能效标识（权限版）


复刻家电能效标签视觉风格的小米背屏 MAML 主题，**权限版需搭配 UriRoute 应用运行**，可采集更多硬件参数。

## 预览

![预览图](https://raw.githubusercontent.com/wmqc97/EcoTag-Root/main/effect.png)

## 功能

- 🔋 **能效等级**：根据电池电量自动计算 1～5 级能效等级
- 💾 **存储空间**：显示剩余存储空间
- ⏱️ **开机时长**：显示系统开机时长
- ⚡ **设备电流 / 功率**：实时电流与功率
- 🌡️ **电池温度 / CPU 温度**：双温度监控
- 📊 **CPU 占用率 / 内存占用**：系统资源监控
- 🔋 **电池健康 / 电池容量**：电池状态信息
- 📱 **Android 版本 / 手机型号**：设备信息
- 🔌 **充电状态**：实时充电状态
- 💡 **电量胶囊**：胶囊电池 UI，支持充电流光动画
- 🌙 **AOD 常亮**：熄屏显示，自动切换省电模式
- ⚙️ **4 个可配置槽位**：用户可自由选择显示参数

## 与主题版区别

| 特性 | 主题版 | 权限版 |
|------|--------|--------|
| 依赖 | 无额外应用 | 需 UriRoute 应用 |
| 数据来源 | 系统 ContentProvider | UriRoute 脚本采集 |
| 可显示参数 | 存储/内存/步数（固定） | 13 种参数（4 槽位自由选择） |
| 硬件参数 | ❌ | ✅ 电流/功率/温度/CPU 等 |
| 刷新间隔 | 系统控制 | 自定义（默认 600 秒缓存） |

## 文件结构

```
├── manifest.xml        # MAML 主题布局文件
├── var_config.xml      # 用户可配置变量
├── effect.png          # 预览图
├── spec.js             # UriRoute 数据采集脚本（337 行）
├── uriroute.json       # UriRoute 脚本配置
├── widget_info.json    # REAREye 组件仓库配置
├── strings/            # 多语言资源（zh_CN）
├── AGENTS.md           # 技术架构说明
└── README.md
```

## 安装

1. 确保已安装 UriRoute 应用
2. 在 REAREye 组件仓库安装本主题
3. 在 UriRoute 中导入 `spec.js` 和 `uriroute.json`
4. 在变量配置中设置 4 个槽位对应的参数编号

## 变量配置

| 变量名 | 类型 | 说明 |
|--------|------|------|
| `hideCapsule` | 开关 | 隐藏电量胶囊 |
| `customTitle` | 文本（≤20字） | 自定义标题 |
| `customSubtitle` | 文本（≤30字） | 自定义副标题 |
| `slot1` ~ `slot4` | 数字 | 4 个显示槽位的参数编号（0-13） |
